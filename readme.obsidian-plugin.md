# Obsidian Plugin configuration

Deel van het maken van de raadsinfoinator is geweest een onderzoek naar plugins voor obsidian die al bestaan en die acties kunnen uitvoeren die wij ook nodig hebben of die wellicht nuttig zijn. 

In eerste instantie verzamel ik hier een '.obsidian' dir met config files van die bestaande plugins. Door deze bv te kopiëren in een Obsidian Vault heb je meteen een plugin-configuratie waarmee je aan de slag kunt. 

Enkele mogelijk interessante plugins: 

- PromptCrafter
- ai_plugin: local, ollama. 
- ai_editor / buszk
	- create yr own commands
	- OpenAI
	- mogelijk item in dropdown toevoegen: "output in nieuwe file"
